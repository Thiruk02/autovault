# AutoVault – Premium Luxury Dealership

AutoVault is a state-of-the-art web application for a premium luxury car dealership. The site features rich aesthetics, responsive design, sleek slide transitions, interactive car carousels, and modern user interface components.

---

## 🚀 Getting Started

Follow the instructions below to get a local copy of the project up and running.

### 📋 Prerequisites

Before installing the project, make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) (Node Package Manager)

### 🔧 Installation

1. **Navigate to the project root directory**:
   ```bash
   cd autovault
   ```

2. **Install the dependencies**:
   ```bash
   npm install
   ```

### 💻 Running the Application

* **Start the local development server**:
   ```bash
   npm run dev
   ```
   *This starts the Vite development server. Open the URL shown in your terminal (typically `http://localhost:5173/` or `http://localhost:5174/`) to view the application.*

* **Build the application for production**:
   ```bash
   npm run build
   ```
   *This compiles and bundles the assets into highly optimized static files in the `dist/` directory.*

* **Preview the production build locally**:
   ```bash
   npm run preview
   ```

## 🎨 Implemented Features & Sections

- **Navigation Bar**: Responsive header that dynamically detects scrolling and includes interactive dropdown submenus.
- **Hero Section**: Features background assets, premium typography, and an interactive car filtering/searching box.
- **Brands Carousel**: Sliding brand selection allowing users to browse listings by car make.
- **Amazing Cars Coverflow**: Custom coverflow carousel showing large active car detail cards with side previews and specifications.
- **Featured Cars Carousel**: Auto-rotating slideshow presenting premium models, specifications, photos, and video counts.
- **About Section**: Overlapping image collage, custom statistics card overlay, and a modern learn more action button.
- **Full-Width Video Banner**: Edge-to-edge video preview section complete with overlay filters and custom hover play button scales.
- **Why Choose Us Grid**: Grid of service features displaying competitive pricing, 24h support, maintenance, and safety details.
- **Testimonials Slide**: Client review carousel showing rating stars, feedback texts, and customer profiles.
- **Footer**: White-logo grid containing a newsletter subscription form, legal links, working hours, contact info, and custom social link circles.

## 🛠️ Technology Stack

- **Core**: React 19 & Vite
- **Styling**: Plain CSS (Variable-based colors/shadows) & Bootstrap 5 (for grid layout structure)
- **Icons**: Bootstrap Icons
